ConsRank-defunct {ConsRank}R Documentation

Defunct functions in ConsRank

Description

These functions have been removed from ConsRank. Use the alternatives listed below.

Usage

EMCons(...)

QuickCons(...)

BBFULL(...)

FASTcons(...)

DECOR(...)

FASTDECOR(...)

labels(...)

Details

  • EMCons: Use consrank with algorithm = "BB"

  • QuickCons: Use consrank with algorithm = "quick"

  • BBFULL: Use consrank with algorithm = "BB" and full = TRUE

  • FASTcons: Use consrank with algorithm = "fast"

  • DECOR: Use consrank with algorithm = "decor"

  • FASTDECOR: Use consrank with algorithm = "fastdecor"

  • labels: Functionality merged into rank2order
