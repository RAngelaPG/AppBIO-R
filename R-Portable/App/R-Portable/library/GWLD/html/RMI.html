RMI {GWLD}R Documentation

Compute pairwise linkage disequilibrium with reduced mutual information

Description

Compute pairwise linkage disequilibrium with reduced mutual information

Usage

RMI(g1, g2, cores = 1, ...)

## S4 method for signature 'data.frame,ANY'
RMI(g1, cores = 1)

## S4 method for signature 'matrix,ANY'
RMI(g1, cores = 1)

## S4 method for signature 'numeric,numeric'
RMI(g1, g2)

Arguments

g1

vector,dataframe or matrix containing genotype coded with interger(0, 1, 2, NA)

g2

vector(ignored if g1 is a dataframe or matrix)

cores

thread number

...

optional arguments (ignored)

Value

a matrix, row names are the same as column names.

Examples

g0 <- c('T/A', NA, 'T|T', NA, 'T|A', NA, 'T|T', 'T/A','T/T', 'T/T',
        'T/A', 'A|A', 'T/T', 'T|A', 'T/A', 'T|T', NA, 'T|A', 'T/A', NA)

g1 <- c('C/A', 'C/A', 'C/C', 'C/A', 'C/C', 'C/A', 'C/A', 'C/A',
       'C/A', 'C/C', 'C/A', 'A/A', 'C/A', 'A/A', 'C/A', 'C/C',
       'C/A', 'C/A', 'C/A', 'A/A')

gt <- data.frame(g0, g1)
geno012 <- codegeno(gt, "/|")
RMI(geno012, cores=2)

g2 <- recode(g0,"/|")
g3 <- recode(g1,"/")

RMI(g2,g3)

g4 <- data.frame(g2, g3)

RMI(g4, cores=2)
