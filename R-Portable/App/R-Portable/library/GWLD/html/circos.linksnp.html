link snp

Usage

circos.linksnp(
  data,
  ylim = c(0, 1),
  color.theme = "viridis",
  track.height = 0.05,
  legend.show = TRUE,
  legend.position = c(0.88, 0.75),
  legend.fontsize = 12,
  legend.limits = NULL,
  legend.breaks = NULL,
  legend.labels = NULL,
  legend.n.breaks = NULL,
  family = NULL,
  bg.border = "black",
  bg.col = NULL,
  lwd = par("lwd"),
  lty = par("lty"),
  ...
)

Arguments

data

A data frame with 7 columns;Chr_1, Pos_1, ID_1, Chr_2, Pos_2, ID_2 value

ylim

Range of data on y-axis

color.theme

The color theme in the legend

track.height

Height of the track

legend.show

logical whether to show the legend

legend.position

legend position

legend.fontsize

the font size of legend

legend.limits

A numeric vector of length two providing limits of the scale

legend.breaks

A numeric vector of positions

legend.labels

A vector giving labels (must be same length as legend.breaks)

legend.n.breaks

An integer guiding the number of major breaks

family

The font family of legend

bg.border

Color for the border of the plotting regions

bg.col

Background color for the plotting regions

lwd

The line width

lty

The line type

...

other graphical parameters
