save the plots

Description

save the plots

Usage

savefig(
  filename,
  plots,
  width = NULL,
  height = NULL,
  dpi = 300,
  units = NULL,
  device = NULL,
  scale = 1,
  ...
)

Arguments

filename

output filename of plot.

plots

Plot to save.

width

plot size.

height

plot size.

dpi

Plot resolution.

units

"in", "cm", "mm", or "px".

device

Device to use,Can either be a device function. one of "pdf", "png", "jpg", "jepg", "tiff".

scale

Multiplicative scaling factor.

...

Other arguments passed on to the graphics device function, as specified by device.
