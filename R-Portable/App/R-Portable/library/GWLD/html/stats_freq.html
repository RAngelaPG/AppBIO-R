stats_freq {GWLD}R Documentation

stats allele frequency stats allele frequency of character genotypes vector

Description

stats allele frequency

stats allele frequency of character genotypes vector

Arguments

vector

a character vector of genotypes

sep

the separator for character genotypes(i.e., "" ,"/", "|")

Value

list

Examples


g0 <- c('T/A', NA, 'T|T', NA, 'T|A', NA, 'T|T', 'T/A','T/T', 'T/T', 
        'T/A', 'A|A', 'T/T', 'T|A', 'T/A', 'T|T', NA, 'T|A', 'T/A', NA)

stats_freq(g0, "/|")
