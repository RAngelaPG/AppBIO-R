Calculated some different indices.

The following functions can be used for the estimation of Selection Index(SI):

BLPSI: Base Linear Phenotypic Selection Index.
SmithIndex: Linear Phenotypic Selection Index.
ESIMIndex: Eigen Selection Index Method.
PPGLPSI: Predeterminated Proportional Gain Linear Phenotypic Selection Index.
KNIndex: Restrictive Linear Phenotypic Selection Index.
RESIMIndex: Restrictive Eigen Selection Index Method.
LTIndex: Linear Marker Selection Index.
MESIMIndex: Molecular Eigen Selection Index Method.
LGSI: Linear Genomic Selection Index.
