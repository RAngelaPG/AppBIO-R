MESIMIndex {Rindsel}R Documentation

Molecular Eigen Selection Index Method

Description

Funtion for MESIM selection index

Usage

MESIMIndex(datos,file.wgt,selval,design,corr,method,out="outextLT.txt",outcsv="outLT.csv",
rawdata,file_nameMARK,one.env,block.ex,softR,file.covG)

Arguments

datos

dataframe object which contains the traits (columns) and entries (rows)

file.wgt

Text file in comma separated values (*.csv) format whose columns are: names of the traits, indicator variable for selected traits, economic weights or signs of the traits and indicator variable for restricted traits.

selval

Percent of selected genotypes (5, 10, 20, etc.). Default is selval=5.

design

Field design ("lattice", "rcb", "AdjMeans"). Default is design="lattice".

corr

Selection index is based on variances-covariances matrix (FALSE) or correlation matrix (TRUE). Default is corr=FALSE.

method

Choose between "vanraden" or "classic" for create the relationship marker matrix.

out

Output file name. Default is out="out.txt".

outcsv

Output file in format *.csv. Default is outcsv="out.csv".

rawdata

If genotypic and phenotypic variances are already calculated, then it can be used to calculate directly the index by setting rawdata=FALSE. Default is TRUE.

file_nameMARK

Text file in comma separated values (*.csv) format whose columns are markers and rows entries.

one.env

Use FALSE for multienviromrent trials.

block.ex

Use FALSE always.

softR

Use "" always.

file.covG

When design is "AdjMeans" and rawdata is FALSE, write the location of your variance and covariance matrix csv file.

Details

MESIM is a generalization of ESIM to the case in which is incorporated MM information to IS, similarly as in the IS Lande and Thompson (1990). Following the basic idea of Kempthorne and Nordskog (1959), Ceron-Rojas et al. (2008b), maximized the correlation between Y_M =β'_p*P +β'_s*S =β'_M*P_{ps} and Z_M =θ'_1*g +θ_2 *s=θ'_M*g_{gs} , ρ_{Y_M Z_M}^2 , where p and g have been defined in Equations 1 and 2, and s is the vector of records of the additive effects of QTLs associated with MM, P'_{ps}=[p' s'] , G'_{gs}=[g' s'] , β'_M=[β'_P β'_s] , and θ'_M=[θ'_1 θ'_2] . In the illustrative example of Lande and Thompson (1990), Y_M = β_p*p + β_s*s , and Z_M = θ_p*G_P + θ _s*s , where p denotes the plant height and s = x_1 α_1 + x_2 α_2 + ... + x_5 α_5.

Again, because ρ_{Y_M Z_M }^2 is invariant to changes in is maximized scale ρ_{Y_M Z_M ^2} under the constraints β '_M*T*β_M = 1 and θ '_M*K*θ_M = 1 , so in MESIM, it is necessary maximize

(θ '_M*K*β_M-1 )^2-μ(β '_M*T*β_M-1) -ω(θ '_M*K*θ_M-1 )

With respect to β_M , θ_M , μ , and ω , where β_M is the vector of coefficients MESIM , θ_M is the vector of coefficients Z_M =θ'_M* g_{gs} and μ and ω are Lagrange multipliers. Ceron-Rojas et al. (2008b) found that the solution is equal

(Q-μ I)β_M=0

where Q=T^{-1}*K . Thus, in MESIM , the value that maximizes ρ_{Y_M Z_M} ^ 2 under the constraints β '_M*T*β_M=1 and θ '_M*K*θ_M=1 is the first eigenvalue ( μ ) Matrix Q , and the vector for building Y_M (With maximum correlation with Z_M =θ'_M* g_{gs} is the first eigenvector ( β_M matrix Q .

Value

The MESIM selection index and an output file which contains the selected entries and other useful information.

Examples

library(Rindsel)
datos<-data.frame(read.csv("https://raw.githubusercontent.com/RAngelaPG/RIndSel-R/main/data/C1_PSI_05_Phen.csv",header=T,na.strings=c(NA,".","-"))) #Raw data to analized.
datos$REP=as.factor(datos$REP)                                                                     #transform to factor.
datos$Block=as.factor(datos$Block)                                                                 #transform to factor.
datos$ENTRY=as.factor(datos$ENTRY)                                                                 #transform to factor.
file.wgt<-"https://raw.githubusercontent.com/RAngelaPG/RIndSel-R/main/data/weights_C1_PSI.csv"     #name of the file where we write the economic weights and restrictions. 
selval<-5                                                                                          #Selection intensity.
design<-"lattice"                                                                                  #Experimental design.
corr<-FALSE                                                                                        #You can decide if you want to work with the correlation matrix instead of variance and covariance matrix.
method<-"vanraden"																				   #For create the relationship marker matrix.
rawdata<-TRUE                                                                                      #By default is TRUE when you are using design option "lattice" or "rcbd", use FALSE for design option "AdjMeans".
file_nameMARK<-"https://raw.githubusercontent.com/RAngelaPG/RIndSel-R/main/data/C1_PSI_S2_05_Haplo.csv")   #name of the file markers information.
one.env<-TRUE                                                                                      #Use FALSE for multienviromrent trials.
block.ex<-FALSE                                                                                    #Use FALSE always.
softR<-""                                                                                          #Use "" always.
file.covG<-""                                                                                      #When design is "AdjMeans" and rawdata is FALSE, write the location of your variance and covariance matrix csv file.
MESIMIndex(datos,file.wgt,selval,design,corr,method,out="outextMESIM.txt",outcsv="outMESIM.csv",rawdata,file_nameMARK,one.env,block.ex,softR,file.covG)
file.show("outextMESIM.txt")
