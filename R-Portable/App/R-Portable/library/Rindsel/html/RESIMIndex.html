RESIMIndex {Rindsel}R Documentation

Restrictive Eigen Selection Index Method

Description

Funtion for restrictive eigen selection index method

Usage

RESIMIndex(datos,file.wgt,selval,design,corr,out="outextBLPSI.txt",outcsv="outBLPSI.csv",
rawdata,one.env,block.ex,softR,file.covG)

Arguments

datos

dataframe object which contains the traits (columns) and entries (rows)

file.wgt

Text file in comma separated values (*.csv) format whose columns are: names of the traits, indicator variable for selected traits, economic weights or signs of the traits and indicator variable for restricted traits.

selval

Percent of selected genotypes (5, 10, 20, etc.). Default is selval=5.

design

Field design ("lattice", "rcb", "AdjMeans"). Default is design="lattice".

corr

Selection index is based on variances-covariances matrix (FALSE) or correlation matrix (TRUE). Default is corr=FALSE.

out

Output file name. Default is out="out.txt".

outcsv

Output file in format *.csv. Default is outcsv="out.csv".

rawdata

If genotypic and phenotypic variances are already calculated, then it can be used to calculate directly the index by setting rawdata=FALSE. Default is TRUE.

one.env

Use FALSE for multienviromrent trials.

block.ex

Use FALSE always.

softR

Use "" always.

file.covG

When design is "AdjMeans" and rawdata is FALSE, write the location of your variance and covariance matrix csv file.

Details

RESIM is a generalization of ESIM to the case in which are incorporated restrictions on Y=β'p , the procedure for set the β is, therefore, very similar to ESIM and is based on IS restricted Kempthorne and Nordskog (1959). So, suppose you have q variables and phenotypic want to improve the means of q-r of them while r of them average remain unchanged, the index Y=β'p should maximize ρ_{YZ}^2 under conditions tale. Again, the restrictions are introduced by the matrix W of 0s and 1s, where 1s indicate that the mean values of the variables Phenotypic remain unchanged, while indicating 0s average changes in phenotypic variables, such that W'G β=0 . Let C= GW, since ρ_{YZ} is invariant under changes of scale can be assumed which β'*P*β=1 and θ'Gθ=1 , so ρ_{YZ}^2 be maximized under the constraints β'C=0 , β'*P*β=1 and θ'Gθ=1 . Let μ , ω and v'=[v_1 ... v_r] Lagrange multipliers. It should maximized

Φ = (θ '_M*K*β_M-1 )^2-μ(β '_M*T*β_M-1) -ω(θ '_M*K*θ_M-1 )-v'C'β

In deriving Φ over β , θ , μ , ω , and v'=[v_1 ... v_r] , Ceron-Rojas et al. (2008a) showed that

(Q-ω I)β=0

where now Q=[I-P^{-1}C(C'P^{-1}C)^{-1}P^{-1}G] . Thus, RESIM, the value that maximizes ρ _{YZ}^2 under the constraint β'P β = 1 , θ'G θ = 1 and β'C=0 is the first eigenvalue ( ω) of the matrix Q , and the vector lets build resim Y=β'p (with maximum correlation with Z=θ'g is the first eigenvector ( β matrix Q

Value

The RESIM selection index and an output file which contains the selected entries and other useful information.

Examples

library(Rindsel)
datos<-data.frame(read.csv("https://raw.githubusercontent.com/RAngelaPG/RIndSel-R/main/data/C1_PSI_05_Phen.csv",header=T,na.strings=c(NA,".","-"))) #Raw data to analized.
datos$REP=as.factor(datos$REP)                                                                     #transform to factor.
datos$Block=as.factor(datos$Block)                                                                 #transform to factor.
datos$ENTRY=as.factor(datos$ENTRY)                                                                 #transform to factor.
file.wgt<-"https://raw.githubusercontent.com/RAngelaPG/RIndSel-R/main/data/weights_C1_PSI.csv"     #name of the file where we write the economic weights and restrictions. 
selval<-5                                                                                    #Selection intensity.
design<-"lattice"                                                                            #Experimental design.
corr<-FALSE                                                                                  #You can decide if you want to work with the correlation matrix instead of variance and covariance matrix.
rawdata<-TRUE                                                                                #By default is TRUE when you are using design option "lattice" or "rcbd", use FALSE for design option "AdjMeans".
one.env<-TRUE                                                                                #Use FALSE for multienviromrent trials.
block.ex<-FALSE                                                                              #Use FALSE always.
softR<-""                                                                                    #Use "" always.
file.covG<-""                                                                                #When design is "AdjMeans" and rawdata is FALSE, write the location of your variance and covariance matrix csv file.
RESIMIndex(datos,file.wgt,selval,design,corr,out="outextRESIM.txt",outcsv="outRESIM.csv",rawdata,one.env,block.ex,softR,file.covG)
file.show("outextRESIM.txt")
