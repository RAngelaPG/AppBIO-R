twas.tx {TWAS}R Documentation

Sample transcriptome data for package twas.

Description

twas.tx is a list containing two data.frames as follows:

Usage

twas.tx

Format

transcriptome - A data.frame of 922 rows with one ID column and 4 columns of gene expression:

ID

subject identifier

COL5A2

COL5A2 RNASeq transcript counts

LRRC16A

LRRC16A RNASeq counts

SLC9A8

SLC9A8 RNASeq counts

PDIA5

PDIA5 RNASeq counts

genotypes - A data.frame of 922 rows with one ID column and genotypes for 30 markers

ID

subject identifier

rs13392501

genotypes for marker rs13392501

etc...
