normalise_coordinates {breedR}R Documentation

Normalise coordinates specification

Description

If checks succeed, returns a complete normalised specification.

Usage

normalise_coordinates(x, where = "")

Arguments

x

matrix-like object to be checked

where

string. Model component where coordinates were specified. For error messages only. E.g. where = 'genetic component'.

Value

a two-column data.frame, with numeric values.
