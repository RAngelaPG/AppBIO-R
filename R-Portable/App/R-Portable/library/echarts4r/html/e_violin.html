e_violin {echarts4r}R Documentation

Violin chart

Description

Draw a violin chart with scattered dots.

Usage

e_violin(
  e,
  name = "violin",
  legend = TRUE,
  y_index = 0,
  x_index = 0,
  symbolSize = 10,
  areaOpacity = 0.5,
  binCount = 100,
  bandWidthScale = 1,
  ...
)

Arguments

e

An echarts4r object as returned by e_charts or a proxy as returned by echarts4rProxy.

name

name of the serie.

legend

Whether to add serie to legend.

x_index, y_index

Indexes of x and y axis.

symbolSize

overall size of symbol.

areaOpacity

opacity of violin area.

binCount

number of bins for violin plot. More bins will provide a more detailed version of the plot,

bandWidthScale

scale for the amplitude of violin area

...

additional options

See Also

official documentation

Examples


PlantGrowth |>
  e_charts(group) |>
  e_scatter(weight) |>
  e_violin(binCount = 200)
