dummy.dimnames {ff}R Documentation

Array: make dimnames

Description

makes standard dimnames from letters and integers (for testing)

Usage

dummy.dimnames(x)

Arguments

x

an array

Value

a list with character vectors suitable to be assigned as dimnames to x

Author(s)

Jens Oehlschlägel

See Also

dimnames

Examples

  dummy.dimnames(matrix(1:12, 3, 4))
