unclass_- {ff}R Documentation

Unclassed assignement

Description

With unclass<- you can circumvent class dispatch on the assignment operator

Usage

unclass(x) <- value

Arguments

x

some object

value

the value to be assigned

Value

the modified object

Author(s)

Jens Oehlschlägel

See Also

unclass, undim

Examples

  x <- factor(letters)
  unclass(x)[1:3] <- 1L
  x
