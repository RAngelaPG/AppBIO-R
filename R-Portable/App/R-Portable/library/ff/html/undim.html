Undim

Description

undim returns its input with the dim attribute removed

Usage

undim(x)

Arguments

x

an object

Value

x without dim attribute

Author(s)

Jens Oehlschlägel

See Also

unclass<-, unclass, unname, dim

Examples

  x <- matrix(1:12, 3)
  x
  undim(x)
