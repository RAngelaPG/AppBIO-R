Virtual storage mode of ffdf

Description

Function vmode returns the virtual storage mode of each ffdf column

Usage

## S3 method for class 'ffdf'
vmode(x, ...)

Arguments

x

ffdf

...

ignored

Value

a character vector with one element for each column
