Description

Use prettyNum() to format numbers

Usage

fmt_pretty(big.mark = ",", ..., scientific = FALSE)

Arguments

big.mark, scientific, ...

Passed to prettyNum().

Value

An object you can pass into number_format().

See Also

Other format functions: fmt_percent()

Examples


jams$Sales <- c(
  "Sales", 35000,
  55500, 20000
)
set_number_format(
  jams, -1, "Sales",
  fmt_pretty()
)
