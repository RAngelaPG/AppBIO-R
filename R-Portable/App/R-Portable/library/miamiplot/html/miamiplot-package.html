miamiplot: Create a ggplot2 miami plot

Description

This package can be used to create a Miami plot, with the chromosome labels bisecting the middle of the plot. The output is a ggplot2 object. Users can specify which data they want plotted on top vs. bottom , whether to display significance line(s), what colors to give chromosomes, and what points to label.
