pak_sitrep {pak}R Documentation

pak SITuation REPort

Description

It prints

  • pak version,

  • platform the package was built on, and the current platform,

  • the current library path,

  • versions of dependencies,

  • whether dependencies can be loaded.

Usage

pak_sitrep()
