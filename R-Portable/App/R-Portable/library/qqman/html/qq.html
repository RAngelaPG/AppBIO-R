qq {qqman}R Documentation

Creates a Q-Q plot

Description

Creates a quantile-quantile plot from p-values from a GWAS study.

Usage

qq(pvector, ...)

Arguments

pvector

A numeric vector of p-values.

...

Other arguments passed to plot()

Value

A Q-Q plot.

Examples

qq(gwasResults$P)
