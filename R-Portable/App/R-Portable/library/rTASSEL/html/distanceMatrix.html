distanceMatrix {rTASSEL}R Documentation

Create a TASSEL distance matrix

Description

This function will calculate a distance matrix using TASSEL's DistanceMatrix plugin.

Usage

distanceMatrix(tasObj)

Arguments

tasObj

an rTASSEL TasselGenotypePhenotype object

Value

Returns a 'TasselDistanceMatrix' object.
