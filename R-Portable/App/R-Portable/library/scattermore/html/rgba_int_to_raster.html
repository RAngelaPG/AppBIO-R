rgba_int_to_raster

Description

Create a raster from the given RGBA matrix.

Usage

rgba_int_to_raster(i32RGBA)

Arguments

i32RGBA

Integer RGBA matrix (with all values between 0 and 255).

Value

The matrix converted to raster.
