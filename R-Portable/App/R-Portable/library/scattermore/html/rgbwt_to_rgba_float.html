rgbwt_to_rgba_float

Description

Convert RGBWT matrix to floating-point RGBA matrix, suitable for alpha-blending.

Usage

rgbwt_to_rgba_float(fRGBWT)

Arguments

fRGBWT

The RGBWT matrix.

Value

RGBA matrix, output is premultiplied by alpha.
