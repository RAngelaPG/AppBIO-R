Data for a 2-factor factorial with a CRD

Description

This data set contains data for ascorbic acid content in mg/100g dry weight (asc.dw), ascorbic acid content in mg/100g fresh weight (asc.fw), and dry matter percentage (dm) for an experiment with 46 potato genotypes (geno), 2 treatments (treat), cooked and crude, and 3 replications (rep) with a CBD.

Usage

asc

Format

A data frame with 282 rows and 6 columns.

Source

International Potato Center, potato experimental data.
