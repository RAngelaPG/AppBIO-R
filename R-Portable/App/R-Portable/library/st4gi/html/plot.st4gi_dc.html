plot.st4gi_dc {st4gi}R Documentation

Data consistency visualization

Description

This function produces a visualization of data consistency.

Usage

## S3 method for class 'st4gi_dc'
plot(x, ...)

Arguments

x

An object of class checkdata.

...

Additional plot arguments.

Details

It produces a visual matrix representation of data consistency problems.

Value

It returns a plot.

Author(s)

Raul Eyzaguirre.

Examples

checks <- check.data.sp(pjpz09)
plot(checks)
checks <- check.data.pt(potatoyield)
plot(checks)
