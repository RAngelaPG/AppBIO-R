Some traits for a multi-environment trial (MET)

Description

This data set has data for root yield in tons per hectare (rytha), beta-carotene (bc), dry matter (dm), starch (star) and number of commercial roots (nocr) for an experiment with 8 sweetpotato genotypes (geno), 2 locations (loc), and 2 replications (rep) in each location following a RCBD.

Usage

spg

Format

A data frame with 32 rows and 8 columns.

Source

International Potato Center, sweetpotato experimental data.
